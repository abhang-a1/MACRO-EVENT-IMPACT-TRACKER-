# MACRO-EVENT-IMPACT-TRACKER-

Developed a Python Tkinter app that analyses macroeconomic events’ impact across asset classes using FRED and Yahoo Finance APIs, delivering real-time data, advanced financial metrics, and interactive visualizations for timely market insights.

•	Engineered robust data validation, time zone-aware processing, and error handling to ensure accuracy and reliability.

•	Enabled multi-asset correlation analysis and customizable event windows to support informed investment decision-making.
